The older sections below it were written before the folder tree, compact library, dialogs and menus; where they disagree, the first section is the current one.

Frames with no Qt screen yet

Onboarding Not started

First-run flow of ten frames: welcome and media folder, then theme and shortcut introduction. Listed as next after Dialogs in the plan.

  • Folder picker feeds the media library (the current first-run wizard only adds folders).
  • Theme choice should write the same setting as Settings, General.
  • The video asks for a shortcut introduction at the end.

Keyboard Shortcuts dialog Partly

The menu entry already opens the Controls page of Settings. The Figma frame is a separate dialog, with the hotkeys moved out of Settings.

Home and sidebar entries Partly (built 2026-10-28)

Home, Videos and Music exist. The frame also has these rows and sections:

  • Network, Playlists, Recent and Add item (pinned folders and playlists) in the sidebar.
  • Listen Again and Frequently Visited Folders rows on Home.

These need new pages or models, so they were left on purpose until now.

New Playlist Partly (built 2026-10-28)

Name field and file selection, plus the playlist context menu. VLC's library has playlists, but not this dialog.

Add Subtitles to Playlist Left on purpose

Add subtitles to a file, a folder or a playlist, from this computer or OpenSubtitles, matched automatically or one by one for every episode. VLC has no batch matching backend.

Setting Presets and Profiles Left on purpose

Per-show presets for subtitle and audio settings (delay, font, default track) and saved control bar layouts as profiles. VLC stores neither per show, so this is new storage plus UI.

Audio and video effect frames Partly

Equalizer, compressor, video essential, colours and crop are side-panel cards. These frames are still on the old Effects window (reached from Open Advanced Settings):

  • Spatializer and Stereo Widener settings.
  • Audio visualizer picker, HDR options and the EQ presets list.

Player: hide UI and customise Partly

The Customize Player modal is done. The hide-UI state (an option in the right-click menu and a shortcut, per the video) is not confirmed in the notes: check it.
